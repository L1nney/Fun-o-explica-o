Função Quadrática

Estudo completo da função:

f(x) = x² - 4x + 3

📌 1. Coeficientes

Identificando a, b e c:

• a = 1 (curvatura)
• b = -4 (inclinação)
• c = 3 (interseção Y)
O que é: Como a = 1 > 0, a parábola tem concavidade voltada para cima (formato de sorriso).

📍 2. Ponto no Eixo Y

Onde a curva cruza o eixo vertical (x = 0):

f(0) = (0)² - 4(0) + 3
Ponto: (0, 3)
O que é: É sempre o valor isolado c, pois quando x = 0 todos os outros termos zera.

📐 3. Cálculo do Delta (Δ)

Discriminante da função:

Δ = b² - 4ac
Δ = (-4)² - 4(1)(3)
Δ = 16 - 12 = 4
O que é: Como Δ = 4 > 0, a função possui duas raízes reais e distintas.

🎯 4. Raízes (Fórmula de Bhaskara)

Onde o gráfico cruza o eixo X (y = 0):

x = (-(-4) ± √4) / 2(1)
x1 = (4 + 2) / 2 = 3
x2 = (4 - 2) / 2 = 1
O que é: Os pontos onde a curva toca o chão (eixo X) são (1, 0) e (3, 0).

⛰️ 5. Vértice (Ponto de Mínimo)

O ponto mais baixo da parábola:

Xv = -b / 2a = 2
Yv = -Δ / 4a = -1
Vértice: (2, -1)
O que é: É a "curva da parábola". Como a > 0, este é o menor valor que a função atinge.
