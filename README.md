# 📐 Apresentação Interativa: Função Quadrática

Projeto interativo desenvolvido para apresentação escolar sobre **Função Quadrática (Função do 2º Grau)**, focando no estudo completo da função:

$$ f(x) = x^2 - 4x + 3 $$

---

## 🚀 Como Funciona

A apresentação funciona no formato de **Mapa Mental Dinâmico**. Ao pressionar a tecla Espaço, Seta para Direita ou Enter (ou clicar no botão na tela), o site revela passo a passo:

1. **Coeficientes:** Identificação de a, b e c e análise da concavidade.
2. **Corte no Eixo Y:** Cálculo do ponto onde x = 0 (0, 3).
3. **Discriminante (Delta):** Cálculo do Delta.
4. **Raízes (Bhaskara):** Encontro dos pontos (1, 0) e (3, 0).
5. **Vértice:** Localização do ponto de mínimo (2, -1).
6. **Gráfico Interativo:** Renderização da parábola destacando todos os pontos notáveis.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3:** Animações, efeitos visuais e layout responsivo.
- **JavaScript (ES6):** Controle de navegação por teclado e lógica da apresentação.
- **Chart.js:** Biblioteca usada para renderizar o gráfico cartesiano da parábola.
